# Prompt-Pack-holder

Private vault. Public square. A free, ad-free prompt library for smartphone and desktop.

- Live target: https://prompt-pack-holder.grok.me (access is set in Grok Build → Publish)
- Public source: this repository
- Open the app file: [index.html](./index.html)

## What it is
- Personal lists behind **username + 4-digit PIN**
- Prompt editor with copy
- Publish / like / comment on a public feed (device-local in this static v1)
- Language selector on every screen: Deutsch, English, Français, Italiano, Русский
- Palette only: `#FFFFFF` `#E6E6E6` `#2F2F2F` `#C4A882`

## Run locally
Open `index.html` in a browser. No build step. Data stays in localStorage.
